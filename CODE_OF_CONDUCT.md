# Code of Conduct

This project follows a simple contributor standard: be respectful, specific,
and evidence-driven.

## Expected behavior

- Discuss technical trade-offs with concrete examples, commands, logs, or file
  references.
- Keep reviews focused on correctness, reproducibility, maintainability, and
  user impact.
- Credit prior work and preserve third-party license notices.
- Report security or privacy issues through `SECURITY.md` instead of public
  issues.

## Unacceptable behavior

- Harassment, personal attacks, or discriminatory language.
- Publishing private credentials, private data, internal paths, or personal
  information without consent.
- Misrepresenting benchmark results, test coverage, licenses, or provenance.

## Enforcement

Maintainers may edit, hide, or remove content that violates this standard and
may block contributors who repeatedly ignore it.
